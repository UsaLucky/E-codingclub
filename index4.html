🔖 Bookmarks

Week 1 — Problems & Critical Thinking

  • A problem = initial state + goal state.
  • Well-structured: clear goals, known constraints. Ill-structured: vague goals, need creativity.
  • Inductive: specific→general. Deductive: general→specific. Objectivity: remove personal bias.
  • 4 pillars: Decomposition, Pattern Recognition, Abstraction, Algorithm Design.

Week 2 — Problem-Solving Strategies

  • Trial & Error: Thorndike's cat. Algorithm: finite, definite, effective, guaranteed.
  • Heuristics: rule-of-thumb, fast, not guaranteed. Means-End Analysis: Newell & Simon 1972, GPS model.
  • Divide & Conquer: split→solve→merge. Dynamic Programming: memoisation. Backtracking: abandon invalid paths.

Week 3 — Problem-Solving Process

  • Steps: Identification → Analysis → Model → Algorithm → Coding → Testing → Evaluation
  • Von Neumann (1945): Control Unit, ALU, Memory, Input, Output. Stored-program concept.

Week 4 — Algorithms

  • 5 characteristics: Finiteness, Definiteness, Input (≥0), Output (≥1), Effectiveness.
  • Efficiency: Time Complexity (runtime vs input size) + Space Complexity (memory usage).

Week 5 — Flowcharting

  • Oval=Start/End · Parallelogram=I/O · Rectangle=Process · Diamond=Decision
  • Circle=On-page connector · Pentagon=Off-page connector · Double Rectangle=Predefined Process

Week 6 — Pseudocode

  • "Pseudo"=almost/fake. Language-independent. Cannot be compiled. 3 structures: Sequence, Selection, Iteration.
  • WHILE: pre-test (checks before). REPEAT-UNTIL: post-test (runs ≥1, stops when TRUE). MOD=remainder.

Week 9 — SDLC

  • Phases: Planning→Requirements→Design→Implementation→Testing→Deployment→Maintenance
  • Models: Waterfall(linear) · Agile(sprints) · V-Model(test at every stage) · DevOps(CI/CD)
  • IBM: bug after deployment = 100× cost of fixing during development.

Week 10 — Control Structures

  • Selection: if, if-else, if-else if ladder, switch (fall-through without break).
  • Iteration: for(known count, pre-test) · while(pre-test) · do-while(post-test, runs ≥1).
  • break=exit loop · continue=skip current iteration only.
